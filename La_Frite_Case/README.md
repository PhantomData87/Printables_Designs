### 3mf
Prusa slice design files that account for the printer settings I had used, and recommended areas to print removable plastic supports.

### Scad
I had used OpenScad for designing the case, and it came in really helpful when I had to slightly alter the case. If you wish to add a modification towards the case, then simply open the file "Lower_plate.scad" and "Upper_plate.scad" to begin modifying the case. 

The hooks are called "Hook.scad" with two variants: Padded hook & hook. The padded hook determines the negative volume added to the case to accomodate for the printed hook object.

"United_Plates.scad" is a nice visual way to render in the case together and complete. Any mathematical errors should be made apparent when the case is not aligned with each other.

### Stl
The same stl files produced from OpenScad that were later imported into PrusaSlicer 3mf file.
